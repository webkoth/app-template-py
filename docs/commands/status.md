# /status — состояние контура

1. Серверное состояние:
   `ssh ops@<сервер> sudo <слаг>-status`
   Если SSH-доступ отклонён — скажи пользователю, что нужен ops-ключ, и
   продолжай со следующего шага.
2. Последние прогоны:
   `gh run list -L5 --json name,headBranch,status,conclusion,updatedAt`
3. Контроль резервных копий:
   `gh run list --workflow=backup.yml -L3 --json status,conclusion,updatedAt`
4. Сведи в короткий ответ: жив ли процесс, код HTTP, статус последней
   доставки, когда снималась последняя копия.

Живость подтверждает 200. Приложение — SPA: корень отдаёт `index.html` любому,
а на форму входа уводит роутер в браузере, поэтому переброса кодом 307 здесь
не бывает.

Корень отвечает 200 и при лежащей базе — это статика, до неё дело не доходит.
Поэтому по-настоящему живость подтверждает `/api/health`: он ходит в базу и
на недоступной отвечает 503. Ровно его проверяет и доставка.

Данные контура боевые, поэтому свежесть копии в этом списке важнее всего
остального. Копия старше суток — скажи об этом отдельно и первым делом.
