# /status — состояние контура

1. Серверное состояние:
   `ssh <слаг>-ops sudo <слаг>-status`

   Именно алиас `<слаг>-ops`, а не `ssh ops@<адрес>`. Установка заводит в
   `~/.ssh/config` запись `Host <слаг>-ops` со своим `IdentityFile` (шаг G),
   и обращение по адресу под неё не попадает: ssh идёт с ключом по
   умолчанию и получает `Permission denied` — при том что нужный ключ на
   машине есть.

   Отказ — сначала проверь, заведён ли алиас:
   `ssh -G <слаг>-ops | grep -E '^(hostname|user|identityfile) '`
   Видно `hostname` сервера, `user ops` и один `identityfile` с ключом
   контура — алиас на месте, и дело в ключе: его публичную половину должен
   добавить владелец сервера. Вместо этого показан сам слаг как имя хоста и
   список чужих ключей по умолчанию — алиаса нет, и надо вернуться к шагу G
   установки, а не просить доступ.

2. Живость приложения — по адресу контура, а не по серверному скрипту:
   `curl -s -o /dev/null -w "%{http_code}" https://<адрес>/api/health`

   Этот шаг здесь не для полноты. `<слаг>-status` смотрит корень, а корень —
   это `index.html`: он отдаёт 200 и при недоступной базе, то есть
   подтверждает только «процесс жив». `/api/health` ходит в базу и на
   недоступной отвечает 503. Ровно его проверяет доставка.

   Расхождение известное: `<слаг>-status` — общий скрипт провижинера, он
   один на два шаблона, и чинить его пришлось бы сразу для обоих. Пока это
   не сделано, живость подтверждает эта строка, а не первый шаг.

3. Последние прогоны:
   `gh run list -L5 --json name,headBranch,status,conclusion,updatedAt`
4. Контроль резервных копий:
   `gh run list --workflow=backup.yml -L3 --json status,conclusion,updatedAt`
5. Сведи в короткий ответ: жив ли процесс, что ответил `/api/health`, статус
   последней доставки, когда снималась последняя копия.

Живость подтверждает 200 от `/api/health`. Приложение — SPA: корень отдаёт
`index.html` любому, а на форму входа уводит роутер в браузере, поэтому
переброса кодом 307 здесь не бывает.

Данные контура боевые, поэтому свежесть копии в этом списке важнее всего
остального. Копия старше суток — скажи об этом отдельно и первым делом.
